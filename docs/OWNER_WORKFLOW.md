# Content Center: единый порядок для владельца

1. Новый клиент создаётся ТОЛЬКО в Content Center: кнопка «+ Новый клиент» рядом с выбором проекта. При совпадении названия система не создаёт дубликат. В ChatGPT можно подготовить описание компании, ЦА и правила бренда.
2. Данные клиента редактируются ТОЛЬКО в существующем проекте: выберите клиента и нажмите «Настройки клиента». Не создавайте новый проект для правки.
3. Один самостоятельный материал = одна карточка Content Center. Текст, фото, дата, статус и история хранятся там. В ChatGPT готовьте сценарии и формулировки для уже существующего материала. После редактирования в чате переносите утверждённые изменения в эту же карточку.
4. Контентные задачи ведите В КАРТОЧКЕ материала: бриф, чек-лист, сроки. В ChatGPT можно дать поручение ассистенту (написать текст или сценарий), но сообщение в чате не создаёт задачу в Content Center.
5. Согласование, календарь, публикация и отчёт — в Content Center. Клиент получает только ссылку на конкретный материал, не доступ к кабинету.
6. Автоматическая синхронизация двух систем не подтверждена. Не сообщать о сохранении данных в Content Center, пока запись не подтверждена в базе и кабинете. Перед созданием из чата — проверить, нет ли уже материала с таким названием или идентификатором.

Безопасность: создание/редактирование клиентских проектов через owner_create_client и owner_update_client; обе функции проверяют авторизованного пользователя с действующим owner-доступом; новые роли не вводятся.
