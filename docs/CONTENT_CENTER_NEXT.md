# Content Center: продолжение без ролей

В кабинет входит только владелец. Согласование по ссылке даёт клиенту доступ только к конкретному материалу. Другие роли и кабинеты не добавляем.

## Добавлено в этом обновлении
- Раздел Идеи: сохраняйте название, ссылку, заметку и теги для выбранного проекта.
- Создание нового черновика из идеи: исходная идея и материалы не изменяются.
- Поиск по сохранённым ссылкам и заметкам через общий поиск Content Center.
- Сохранение идей в уже существующей таблице assets, без миграции и новых прав.
- Обновление кэша PWA для загрузки новой версии на телефоне.
